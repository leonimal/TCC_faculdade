Procedimento de execução local

Configurar os arquivos locais de ambiente conforme os exemplos do projeto, sem expor credenciais.

Iniciar o MySQL com docker compose -f software/compose.yaml up -d.

Em software/web/, aplicar migrações e seed com npm run db:migrate e npm run db:seed.

Iniciar a aplicação com npm run dev e executar os testes pertinentes antes de demonstrar uma funcionalidade.
