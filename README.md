# Projeto de TCC

**Título:** Desenvolvimento e avaliação técnica de um sistema IoT de baixo custo para monitoramento ambiental em salas de aula

Este workspace reúne o texto acadêmico, a pesquisa bibliográfica, o planejamento, o protótipo e as evidências experimentais do TCC de Ciência da Computação da Universidade Paulista (UNIP), campus Araçatuba.

## Escopo confirmado

Desenvolver e validar um sistema IoT de baixo custo para monitorar temperatura, umidade relativa e iluminância em salas de aula. O sistema deverá adquirir, transmitir, armazenar e apresentar os dados por meio de API, banco MySQL, dashboard, relatórios e alertas.

O monitoramento sonoro foi retirado do escopo avaliado. Uma possível extensão acústica poderá ser discutida apenas como trabalho futuro.
