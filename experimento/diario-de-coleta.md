# Diário de coleta e eventos

Preencher uma cópia por coleta-piloto ou sessão formal de estabilidade operacional. Não registrar senhas, chaves ou dados pessoais.

## Identificação

| Campo | Registro |
|---|---|
| Tipo de execução | Piloto / sessão formal de 8 h / reposição |
| `run_id` | A preencher |
| Data | A preencher |
| Sala | A preencher |
| Local e conectividade | A preencher |
| Responsável | A preencher |
| Dispositivo e firmware | A preencher |
| Intervalo e versão de configuração | A preencher |
| Início efetivo / término efetivo | A preencher |
| Posição, altura e orientação dos sensores | A preencher |
| Instrumento de referência, se houver | A preencher |

## Eventos

| Horário | Categoria | Descrição objetiva | Ação adotada | Registros possivelmente afetados | Impacto na validade |
|---|---|---|---|---|---|
| A preencher | rede / energia / sensor / posição / ambiente / outro | A preencher | A preencher | A preencher | A preencher |

## Encerramento

- Arquivo bruto exportado e preservado: `A preencher`.
- SHA-256 do arquivo bruto: `A preencher`.
- Maior fila, perdas e reenvios observados: `A preencher`.
- Execução candidata a válida: `A preencher`.
- Justificativa: `A preencher`.
